# Changelog

All notable changes to this project.

## [1.8.0] — 2026-11-25

- Catalogue at **968 resources**, every card with a preview and a complete prompt.
- Free-tier resources completed: 344 of 354 public rows carry both a preview and a body; the remaining 10
  publish no preview at all.
- Removed the recipe pack, the track band and every preview-only card, so no card can be opened without a
  readable prompt.
- Source pointers stripped from the shipped data and the UI: the catalogue presents the resources, not where
  they were collected from.

## [1.7.0]

- 190 resources added.
- Category filter collapsed back to 62 labels (type + industry tags).

## [1.6.x]

- Resource import and taxonomy fixes; preview repairs; poster frames captured mid-loop instead of frame 0.
- Library rebuilt as a plain resource gallery.

## [1.5.0]

- Catalogue widened, then trimmed back to preview + prompt cards only.

## [1.0.0]

- First stable release: a static, offline-first catalogue with local previews, filters and prompt export.
