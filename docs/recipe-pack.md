# Recipe pack — UI replication prompts

A pack of prompts that turn "make it look like that site" into a measured workflow: capture the reference,
extract the real values, rebuild it in a known stack, and prove the result with a self-test.

Current pack: **104 prompts** (rea 40 / craft 40 / community 24).

Rows are generated by `node scripts/build_recipe_docs.js` from `data/recipe_pack.json`, which is also
the source the catalog build reads. Preview media is generated by
`python scripts/render_recipe_previews.py --all` from the pure-CSS demos in `scripts/recipe_demo.*`.

## Provenance and licence notes

- Prompt bodies are original syntheses written for this catalog. They are attributed to the repository or
  library whose method or pattern they encode; no upstream prose or shader source is copied verbatim.
- `morluto/rea` is MIT licensed. `storytold/craft-anything` is Apache-2.0.
- Community rows cite the MIT-licensed library or web standard they follow. React Bits is MIT **plus the
  Commons Clause**: its components may be used in apps with attribution, but not resold or redistributed as
  components — the prompts below only describe the pattern, never ship library code.
- Demo media is rendered from original CSS compositions in this repository (MIT), not from upstream sites.

## Add a recipe

1. Append a record to `data/recipe_pack.json` with the fields used above (id, title, description, type, tags,
   palette, prompt, notes, demo, source, sort_order). Use a negative `sort_order` to pin a pack card above the
   scraped catalog.
2. `python scripts/render_recipe_previews.py --ids <id>` to render `assets/previews/<id>.{mp4,webp}`.
3. `node scripts/build.js && node scripts/build_recipe_docs.js`.
4. `node --test scripts/tests/recipe-pack.test.js`.
