Goal: turn a live reference site into a re-runnable evidence baseline before touching any code. Step 1 — launch a dedicated Chromium profile with --remote-debugging-port=9222 --user-data-dir=/tmp/ref-profile and open the reference URL at 1440x900. Step 2 — attach with Playwright over CDP (chromium.connectOverCDP) and drive a declarative JSON scenario, never ad-hoc clicks: goto, wait_for selector or state, wait_for_timeout, scroll_to y, hover, press, screenshot. Declare an explicit timeout on every action and wait for a page-specific ready marker before each capture; a visible container or a fixed 500ms sleep is not readiness. Step 3 — at each step record a viewport screenshot, an eight-frame filmstrip of the intro at 0/120/240/480/720/1000/1500/2000ms, the outerHTML outline of above-the-fold nodes, computed styles for headline, button, media container and page background, and the resource list with transfer sizes. Repeat the run at 390x844 and again with prefers-reduced-motion: reduce. Step 4 — repeat the identical scenario twice and diff the screenshots; only states that match between runs are trustworthy. Rebuild stack: a small Node script plus a checked-in scenario JSON that any teammate can re-run, capturing into evidence/site/date/ with a run log. Acceptance: two runs differ by less than 1 percent of pixels, every captured value is tagged observed, inferred or unknown, and the filmstrip clearly shows the intro start state, peak and settled state.
