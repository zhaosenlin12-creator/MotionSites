Capture the overlays a clean first visit shows, and the ones it hides behind interaction. Start from empty storage in a provider-owned browser so no consent choice is remembered, load the page at 1440x900, and screenshot at 0, 400 and 1200 ms before any click. Then run a declared step sequence: dismiss the consent banner, open the newsletter modal from the footer, close it with its own close control, and reopen it with Escape as the exit. Capture DOM, accessibility tree, screenshot and the active element after every step. For each overlay record role (dialog, complementary, region), aria-modal, labelledby targets, z-index with its stacking-context parent, bounding box, whether focus is trapped, which element takes focus on open, which dismissal targets actually work, and what each panel does to what sits below it: compare the hero's top offset and the scrollbar gutter before and after. A panel that appeared and closed before the observation window armed is unknown, not absent, so every row carries an observed, inferred or unknown tag. Rebuild stack: a native dialog element driven by a small state machine, a focus trap only while modal, a scroll lock that reserves the gutter width, and a consent banner that does not push the header. Acceptance: the inventory names every panel with its stacking number, focus return is asserted after each close, layout below moves less than 1 px across an open-close cycle, and every panel the capture never showed is listed as unknown.
