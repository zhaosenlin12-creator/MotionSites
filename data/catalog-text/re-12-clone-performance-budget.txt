Goal: make the clone measurably as smooth as the reference, not merely close in screenshots. Step 1 — measure the reference with one harness: enable CDP Tracing or the Performance domain, record a ten second idle window plus a scripted scroll through the animated section, and collect frame times, long tasks above 50ms, total main-thread scripting time, layer count and paint area per frame. Read LCP, CLS and INP through PerformanceObserver into a JSON report, and total JS transfer and parse cost from the network log with the CPU throttled four times. Step 2 — run the identical harness against the clone at the same viewport and throttle, then diff the two reports field by field. Step 3 — fix only attributed regressions: forced synchronous layout from reading offsetHeight inside a rAF write loop, animation of non-composited properties such as top, width or box-shadow, a permanent will-change, an IntersectionObserver that leaves rAF running offscreen, an unsized media element causing shift, or an unoptimized bundle. Pause every offscreen animation and cap devicePixelRatio for canvases. Rebuild stack: the harness as a checked-in Node script plus a budget file, with CSS and JS changes limited to transform, opacity and filter. Acceptance: 95th percentile frame time under 16.7ms at 4x CPU throttle, CLS under 0.05, no long task above 200ms during the intro, and a regression report naming the element and property behind any remaining miss.
