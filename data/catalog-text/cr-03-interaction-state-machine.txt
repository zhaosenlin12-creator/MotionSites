Map every interactive control as an explicit state machine before implementing it. For the dropdown, modal, tabs, accordion, toggle and carousel visible in the target, write a table with columns: state, trigger event, guard, next state, side effect, and visible difference with a screenshot crop. Cover at least rest, hover, focus-visible, pressed, open, opening, closing, loading, success, error, empty and disabled. Name timing explicitly, for example closed to open on click or Enter, 180 ms fade plus 8 px rise, focus moves to the first item; Escape closes, focus returns to the trigger, and the exit animation finishes before the node unmounts. Implement each component as a small finite-state machine: one state enum, one transition function, and CSS driven by a data-state attribute so styling cannot drift from logic. Inputs are pointer, keyboard, focus and media query; guards ignore a second click during closing. Acceptance self-tests: scripted runs fire each transition and assert the state attribute, ARIA expanded, selected and disabled, and focus position; every state in the table is reachable in the build; no input path leaves a stale open state; a transition trace log shows no double fire; a keyboard-only run completes the same flows as the pointer run.
