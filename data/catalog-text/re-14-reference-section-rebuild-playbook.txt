Goal: rebuild one section from a reference URL with an auditable chain of evidence. Phase 1, scope: name the section by its DOM anchor and record the reference URL, viewport 1440x900, date and any logged-in state. Phase 2, capture: run the deterministic scenario recipe and store per-step screenshots, the filmstrip, the DOM outline and the resource list under evidence/date/. Phase 3, harvest: pull animation timings from getAnimations(), timeline structure from the site's animation library, resolved transforms and custom properties from computed style, palette by area-weighted clustering, breakpoints by width sweep, and assets from the network log. Write every value into a spec table with a provenance column marked observed, inferred or unknown; anything unobserved gets one line saying why. Phase 4, rebuild: build the section in an empty page first, in the project's real stack, consuming tokens rather than magic numbers, then port it in. Phase 5, verify: screenshot the clone at 1440, 768 and 390, align with the reference, and produce a pixel diff plus a DOM structure comparison; iterate until the diff is under 2 percent of pixels outside text antialiasing. Phase 6, close the loop: run the performance harness, check keyboard focus, reduced motion and horizontal scroll, then write a handoff note listing what matched, what was approximated and what remains unobserved. Acceptance: the diff budget holds at all three viewports, the interaction checklist passes, and no claim in the note lacks an evidence row.
