Record the errors a reference already produces so a rebuild is judged against the same floor. Load the page at 1440x900 with a disposable profile, empty storage and no extensions, then observe for a 10 second window while performing one standard tour: initial load, one scroll to the footer, one click on the primary call to action, one resize to 390 wide. Collect every console entry with level, source URL and line, every page error with its stack, every failed request with status and reason, and every policy violation report. Classify each into expected noise, tolerated noise and real failure: an analytics or consent script throwing on a blocked third party is expected, a broken module import or a 404 on a render-critical asset is a real failure. Keep the classified list with the capture and with the browser build string, because a different build can change the list without the site changing. Then decide what the clone should do with each line: reproduce, silence, or unknown with a reason, and tag every decision observed or inferred. Rebuild stack: a small assertion script that loads the clone, applies the same tour, and fails the build when a new unclassified console error or a render-critical failure appears, while the allowed list is committed next to it. Acceptance: the inventory covers console, page error, failed request and violation families, every entry carries a class and a decision, the clone produces no real failures, and each reproduced entry names the capture it came from.
