Goal: extract visually exact CSS motion without reading a line of minified script. First use the CSSOM: iterate document.styleSheets and cssRules, recursing into CSSKeyframesRule and CSSKeyframeRule to dump the animation name, every offset (from, 50%, to) and each declared property. Wrap cross-origin sheet reads in try/catch; a SecurityError there is a documented gap, not a failure, so download that href from the network log and parse the text instead. Keep only keyframes whose animation-name is referenced by a rendered element (check getComputedStyle(el).animationName) to skip unused vendor rules. Second, read the resolved motion: for each animated element set animation-play-state: paused, step animation-delay to the 0, 25, 50, 75 and 100 percent checkpoints, and decompose the resulting matrix or matrix3d into translate, scale, rotate and perspective so you can rewrite readable transform values. Third, resolve custom properties with getComputedStyle(el).getPropertyValue('--x') and check CSS.registerProperty plus @property blocks for typed, animatable values. Rebuild stack: plain CSS @keyframes and custom properties, with prefers-reduced-motion disabling every animation. Acceptance: the recomposed matrix at all five checkpoints matches the reference within 1e-3 per component, unused rules are excluded, and every cross-origin sheet you could not read appears in the evidence ledger as unobserved.
