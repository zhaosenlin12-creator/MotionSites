Close the rebuild with a scorecard a reviewer can check in one minute. Seven rows, each a number or a yes, each paired with the command that produced it. Token purity: count hex colours and raw pixel values outside the token file, target zero. State coverage: built states over required states per part, target all seven. Themes: both rendered and diffed, with only documented differences allowed. Contrast: measured pairs over pairs below threshold, target zero below. Responsive parity: widths tested and page width against viewport at each, target no sideways scroll. Motion budget: manifest entries and the longest entrance in milliseconds, target under 620. Unverified items: an explicit numbered list that may not be empty unless the first six rows are clean. Add the rule that gives the scorecard its value: a check that could not measure something reports unmeasured and blocks its row, so silence is never rounded up into a green cell. Finish with the date, the widths and browsers used, and the one known gap the team consciously accepts, because a scorecard with no accepted gap is a scorecard nobody read. Acceptance: the scorecard fits one screen and every row cites its evidence; re-running the listed commands reproduces each number within rounding; a deliberately broken token fails exactly the token row; no row reads passed without a measurement behind it.
