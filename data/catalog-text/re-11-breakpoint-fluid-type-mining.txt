Goal: recover the reference's responsive contract numerically. Script the viewport from 320 to 1920 in 20px steps, waiting two frames at each width, and for eight fixed probe elements record display, flexDirection, gridTemplateColumns, fontSize, padding, flex-wrap, order and visibility. Treat any width where one of those values changes as a breakpoint candidate, then narrow each candidate to a single pixel with a binary search. Cross-check against the media queries the page actually declared: hook window.matchMedia before navigation with addInitScript, log every query string and its matches, and read @media and @container blocks from the CSSOM while noting cross-origin sheets you could not parse. Collect the type ramp by sampling fontSize and lineHeight for h1, h2, body and button at ten widths; fit line segments to learn whether the site steps sizes or interpolates with clamp(), and derive the clamp minimum, viewport coefficient and maximum. Note any mobile layout that is a separate DOM tree hidden with display: none, because it breaks focus order. Rebuild stack: mobile-first CSS at the recovered min-width breakpoints, clamp() for fluid type and spacing, and container queries where a component changes independently of the viewport. Acceptance: no breakpoint drifts by more than 1px, the headline size curve stays within 2 percent at six sample widths, and there is no horizontal scroll at 320, 390, 768, 1024, 1440 or 1920.
